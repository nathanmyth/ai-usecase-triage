# Milestones

| # | Milestone | Key deliverables | Exit criteria | Target |
|---|---|---|---|---|
| **M1** | Policy & foundations | PRD, tier taxonomy (ADR-002), `policy.json` v1 reviewed by governance and Legal, repo + CI | Policy signed off; CI green | Week 1 |
| **M2** | Rules engine + eval | Rules engine, labeled eval set (20+ cases), eval harness | Under-classification 0% on eval set (rules only) | Week 2 |
| **M3** | LLM layer + register | LLM classifier, hybrid combiner (ADR-001), register, Streamlit UI | Hybrid eval meets all PRD quality targets | Week 3 |
| **M4** | Pilot | Pilot with 2 business units, reviewer feedback loop, browser demo, retro | 20 real intakes triaged; reviewer agreement ≥ 85%; no under-classifications | Week 5 |

## Critical path
Policy sign-off → labeled eval set → rules engine → hybrid. The labeled eval set is the hidden dependency: it needs governance reviewers' time to label, so it starts in week 1.
